5. Fill in the Missing Code

This web page should be configured as a two-column layout with a right navigation column that is 150px wide with a 1px border.

💡 Solution: The nav needs float: right to move to the right side. The main needs margin-right: 160px to avoid overlapping with the nav. The footer needs clear: both to sit below both columns.

✅ Completed Code:

/* nav — float right, 150px wide, border */ nav { float: right; width: 150px; background-color: #cccccc; border: 1px solid #000000; } /* header styles */ header { background-color: #cccccc; color: #663333; font-size: x-large; border-bottom: 1px solid #333333; } /* main — margin-right to leave space for nav */ main { margin-right: 160px; } /* footer — clear both columns */ footer { font-size: x-small; text-align: center; clear: both; } /* nav links */ nav a { color: #000066; text-decoration: none; } /* remove bullet points */ ul { list-style-type: none; }
