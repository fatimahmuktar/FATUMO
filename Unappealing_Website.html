Ling's Cars - WebPage Analysis

Analyze and evaluate a poorly-designed website

✗ Unappealing Website - Ling's Cars

Ling's Cars is a car rental website with chaotic design, bright clashing colors, and poor organization that makes navigation confusing and visually overwhelming. The site demonstrates multiple design flaws that negatively impact user experience.

a. What is the URL of the website?
https://www.lingscars.com/
b. Does this page use tables? If so, for what purpose?
Yes. Ling's Cars uses tables extensively for page layout in an outdated manner. This approach makes the website difficult to navigate and not mobile-friendly, which is a major design flaw in modern web development.
c. Does this page use CSS? If so, for what purpose?
Yes. CSS is used but poorly executed. It creates:
  • Harsh, clashing colors that hurt the eyes
  • Difficult-to-read text with poor contrast
  • Inconsistent spacing and alignment
  • Overall chaotic visual experience
d. Is this page appealing or unappealing? List three reasons for your answer.
✗ Unappealing
  • Harsh Color Scheme with Clashing Colors: The website uses too many bright, clashing colors that hurt the eyes and make it difficult to focus on content. The color choices lack any professional design sense and create visual chaos.
  • Chaotic and Disorganized Layout: The page layout is disorganized and cluttered, with random elements scattered throughout. This makes it extremely hard to find important information and navigate the website effectively.
  • Outdated and Unprofessional Design: The design looks unprofessional and resembles websites from the 1990s with no modern design principles applied. It lacks contemporary web design standards and best practices.
e. If this page is unappealing, what would you do to improve it?
Suggested Improvements:
  • Redesign the color scheme using a limited, modern palette (white, gray, and one accent color)
  • Reorganize the layout using CSS Grid and Flexbox for a clean, structured design
  • Replace outdated fonts with modern, readable typefaces like Segoe UI or Open Sans
  • Simplify content by removing unnecessary elements and focusing on key information
  • Add smooth CSS animations and transitions for a professional feel
  • Make the website fully responsive and mobile-friendly
  • Improve navigation with clear, intuitive menus and buttons
  • Use high-quality images and apply modern design principles throughout
